# B站刷片分享（AstrBot）

让角色在后台自己刷 B 站，按它自己的口味挑视频，只把**真的觉得有意思**的分享给你。

和"定时转发热榜"最大的区别：**每一条都经过角色本人打分，并且写出了想分享的理由**。分数不够就不推。

## 它是怎么"觉得有意思"的

```
抓候选（热榜 / 分区榜）
      ↓  硬筛：时长、播放量、黑名单、去重
      ↓  粗排：按兴趣标签先过一遍
角色口味评分 ── 0-10 分，同时写一句分享语
      ↓  低于阈值就整轮不推
推送：封面 + 一句话 + 链接
      ↓
用户的反应回流（喜欢就强化对应标签）
```

关键在于**口味不是写死的**，而是从人格设定里推断出来的：

- 懒散的猫系少女 → 搞笑、动物、摸鱼日常，不看游戏
- 认真的人设 → 知识区、纪录片切片，不看鬼畜

`/口味` 可以看它现在觉得自己爱看什么，`/口味重写` 可以推翻重来。

## 推送的克制

主动推送最容易死于"太吵"。内置了这些限制，都可在配置里调整：

- 每天最多 1-2 条（`daily_limit`）
- 两次推送至少间隔 4 小时（`min_interval_hours`）
- 凌晨 0-8 点不推（`quiet_hours`）
- 只推给最近 24 小时说过话的会话（`active_hours`）
- 分数不到 7 分，这一轮直接放弃（`score_threshold`）
- 一句话关掉：`/不推了`

**宁可一天不推，也不推一条凑数的。** 这是它像"朋友分享"而不是"推荐算法"的前提。

## 命令

| 命令 | 作用 |
|---|---|
| `/推一个` | 立刻推一条（也能用来测效果） |
| `/不推了` | 关闭本会话主动推送 |
| `/推送开` | 重新开启 |
| `/口味` | 查看当前口味档案 |
| `/口味重写` | 按当前人设重新推断口味 |

另外，开启 `enable_tool` 并在人格里勾选 `share_video` 后，用户说「有什么好玩的」「好无聊」「你最近在看什么」，AI 会自己推一条。

## 配置要点

| 面板名称 | 默认 | 说明 |
|---|---|---|
| 启用主动推送 | 开 | 关掉后就只剩 `/推一个` |
| 每个会话每天最多推几条 | 2 | 建议 1-2 |
| 两次推送的最短间隔 | 4 小时 | 建议 3-6 |
| 静默时段 | `0-8` | 填 `0-0` 不限制 |
| 推送分数线 | 7 | 调高更挑剔，调低更频繁 |
| 每轮送进模型的候选数 | 8 | 越大越可能挑到好的，token 也越多 |
| 抓取的分区 | 空 | 留空=全站热门；填 `160,217` 就只看生活和动物区 |
| 黑名单关键词 | 一段默认词 | 热榜里时政/擦边不少，建议保留 |

## 已知限制

- **排行榜接口已被风控**。实测 `ranking/v2` 在无 cookie 环境下直接返回 `code -352`，所以主数据源换成了 `popular`（综合热门），翻 3 页凑量；排行榜只在候选不足时补一次，失败就静默跳过。
- **分区过滤是本地做的**。`popular` 不支持按分区请求，配置 `rids` 后是在抓回来的结果里按分区名匹配（填 `160` 就匹配所有含"生活"的分区）。匹配不到时退回全量，避免整轮没候选。
- **不带 cookie**，拿不到弹幕和评论——如果以后想用弹幕判断"这视频好不好笑"，需要额外做登录。
- **搜索接口没做**。B 站搜索需要 wbi 签名和 cookie，容易失效，收益不大，先不碰。
- **只发封面 + 链接，不下载视频本体**。下载会带来流量、存储和版权问题，而且 QQ 里发视频文件体验也不好。
- **接口可能变**。抓取失败只记日志、跳过这一轮，不会报错刷屏。
- **内容安全靠关键词黑名单**，不是严格审核。如果你的群比较敏感，把黑名单配狠一点。

## 和其他插件联动（未实现，留了余地）

这套推送天然适合和已有插件串起来：

- 推视频时附一句语音（TokenPlan TTS 插件）：「你快看这个，笑死我了」
- 或者附一张"它窝在沙发上刷手机"的自拍（TokenPlan 自拍插件）

想象收到的是：一张自拍 + 一句语音 + 一个链接。那就不是"推荐"，是"她在跟你分享生活"。
